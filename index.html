What UNetMine is doing

UNetMine estimates what the selected physical miner would produce today, subtracts modeled electricity and pool costs, and shows the resulting NET MINE amount as a purchase target you control.

Method: expected miner share = miner hashrate ÷ network hashrate; gross coin = share × modeled network miner rewards/day. Then pool fee and modeled electricity cost are deducted. Price can be refreshed from a public market-data endpoint; network assumptions remain editable.

Move your UNetMine dashboard

1. Back up on this computer. Save one .json file containing your local UNetMine settings, miner-day history, reserves, and prototype accounts.

2. Copy both files. Move UNetMine_Portable_Dashboard.html and the backup .json file by USB or another transfer method.

3. Restore on the new computer. Open the HTML dashboard there and use Restore Data below. It replaces the new computer's existing UNetMine demo data.

The dashboard is a virtual-mining prototype; it does not physically mine, trade, connect to a real wallet, or activate real subscriptions. It stores data in this browser, not inside the HTML itself. Keep your backup private because it can include locally entered account information. Live price refresh requires an internet connection; manual prices still work offline.
